# RecordSaaS Assets

Executable FFmpeg assets used by RecordSaaS Desktop.

Owner: [André Luiz](https://github.com/Ddiidev)

## Release Assets

The release keeps the asset names expected by the desktop app:

- `ffmpeg` - Linux x64 (`libx264`, NVENC, VAAPI and QSV)
- `ffmpeg.exe` - Windows x64 (`libx264`, NVENC, AMF, QSV and `gfxcapture`)
- `ffmpeg-darwin-x64` - macOS Intel (`libx264` and VideoToolbox)
- `ffmpeg-darwin-arm64` - macOS Apple Silicon (`libx264` and VideoToolbox)
